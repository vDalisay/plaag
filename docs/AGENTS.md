# Documentation guidance

Keep the Plaag knowledge index brief and descriptive. Navigation should explain a subject, when to read it and the area containing it, without direct links or fixed file paths. Keep exact execution commands in operational guides.

Put durable policy in focused guidance, decisions in plans and observed results in handoffs. Update the existing owner of a fact instead of copying it into each layer. New standalone guidance uses YAML type, title and description metadata; indexes and AGENTS.md remain plain Markdown.

Preserve historical evidence with its date and limitations. Check superseding decisions before presenting an old plan as current. Implementation plans follow the Gameplay verification policy in the guidance area; named acceptance cases describe behaviors, not separate test requirements.
